# RoyalGames 🎮
Royal Games é uma plataforma de catálogo de jogos desenvolvida com foco em organização, gerenciamento e experiência moderna para usuários e administradores.
O projeto possui integração completa entre Frontend e API REST, incluindo autenticação JWT, CRUD de jogos, upload de imagens, paginação, ordenação dinâmica e controle de acesso administrativo.
